# CCC Estructurados Agro

Primer index para el relanzamiento de comunicacion y marketing de CCC.

## Objetivo

- Presentar la nueva narrativa comercial.
- Ordenar el portfolio inicial de estructuras agro.
- Preparar captura de oportunidades para una futura conexion con Supabase.
- Mantener una base simple para publicar en Vercel y migrar luego a Wix.

## Archivos

- `index.html`: contenido y estructura del sitio.
- `styles.css`: direccion visual responsive.
- `script.js`: animacion visual y comportamiento del formulario.
